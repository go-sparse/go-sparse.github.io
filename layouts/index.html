Sparse matrices, in pure Go.
Solvers that count iterations like SciPy.

go-sparse is the sparse linear algebra layer of the Go scientific stack built on go-ndarray: sparse formats, fill-reducing orderings and iterative solvers with preconditioners, following scipy.sparse.linalg. Its tests replay recorded SciPy answers. No cgo. It is in development and not yet released; what is not provided yet (sparse direct factorisations, eigensolvers, multigrid) is said in the documentation.

Why go-sparse

What scipy.sparse gives, in Go.

Each package names the reference it corresponds to: SciPy's scipy.sparse and scipy.sparse.linalg, MATLAB's sparse functions, and SuiteSparse AMD and COLAMD as the reference algorithms for the orderings.

▦

Sparse formats

COO, CSR, CSC and DOK over float64 and complex128; conversions, O(1) transpose, SpMV, SpMM, SpGEMM, Diags, Tril, Triu and norms.

⇄

Orderings

RCM, AMD and COLAMD, with bandwidth, profile and Cholesky and QR fill counts to compare them.

↻

Iterative solvers

CG, GMRES(m), BiCGSTAB, MINRES, LSQR and LSMR, with Jacobi, SSOR, IC0, ILU0 and ILUT preconditioners, on any LinearOperator.

📄

Matrix Market

Read and write coordinate and array files, real, integer, pattern and complex, with limits against hostile input.

🧮

On go-ndarray

The nd package takes and returns *ndarray.Array for vectors, dense matrices, SpMV and SpMM.

📦

Pure Go, CGO=0

No cgo. CI runs the tests with the race detector, on 386 and the other architectures of the fleet.

⚖️

BSD-3-Clause

Every repository of the organization. The orderings are written from the papers; GPL and LGPL code was not consulted.
